# ADR-0002: 采用受控出网 + 模型网关

## 状态

Accepted

## 背景

部署前提是企业内网强隔离，但允许受控出网。系统又要求供应商无关和后续本地模型挂载能力。

## 决策

- 所有模型请求统一走 LiteLLM Proxy
- 只有受控网段允许访问外部模型
- 外部模型访问受预算、策略、审计和路由规则控制

## 后果

### 正面

- 保留模型供应商替换空间
- 统一审计、成本与限流
- 更适合未来接入本地 vLLM/Ollama

### 负面

- 网关成为关键基础设施，需要高可用与治理配置
- 某些供应商特性需要通过适配层暴露

## 替代方案

- 各运行面直接访问模型：不满足治理要求
- 强绑定单厂商 SDK：不满足供应商无关目标
