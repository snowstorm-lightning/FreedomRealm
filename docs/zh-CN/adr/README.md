## ADR 规则

- ADR 必须记录背景、决策、后果和替代方案。
- 已落地的决策发生变化时，必须新增后续 ADR，而不是改写历史。
- 涉及许可证、商标、官方兼容认证或项目更名的 ADR 必须标注需要人工确认。
- 涉及自治能力、GovernanceBrain、模型能力治理、FederationProtocol、Federation 或 Adaptive Runtime 的 ADR 必须说明审批、审计、数据分级和回滚影响。
