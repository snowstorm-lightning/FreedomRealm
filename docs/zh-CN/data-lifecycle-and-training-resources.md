# 数据生命周期与训练资源治理

## 定位

AI-HRMS 管理 HR 事实、协作内容、模型上下文、运行观察、评测样本、学习沉淀、模板资产和跨实例共享摘要。不同数据不能因为进入 AI 流程就失去来源、权限、用途、保留期和删除路径。

本文件补充 [security-and-governance.md](security-and-governance.md)、[environment-isolation.md](environment-isolation.md)、[learning-flywheel.md](learning-flywheel.md) 和 [evals/baseline-v1.md](evals/baseline-v1.md)，用于定义数据从采集、使用、脱敏、保留、训练、共享、撤回到删除的治理边界。

## 核心原则

- 入口即分类：数据进入系统时必须绑定来源、owner、用途、`ProjectInstance`、`dataClassification` 和保留策略。
- 默认最小化：只采集和传递完成任务所需的最小数据。
- 默认不训练：原始用户数据、HR 主数据、内部任务和模型上下文默认不作为训练资源。
- 脱敏后可保留：敏感数据可以在严格脱敏、审批、审计和用途限定后保留为训练资源。
- 衍生数据继承约束：摘要、embedding、报告卡、评测样本、记忆片段和训练资源必须继承原始数据的来源、分类和使用限制，除非经过明确降级审批。
- 公开分享显式授权：任何进入 Community Commons、公开案例库或跨实例共享的资产必须显式授权并通过脱敏检查。

## 数据类别

| 类别 | 示例 | 默认处理 |
| --- | --- | --- |
| 业务主数据 | 组织、账号、员工档案、考勤、权限 | 控制面维护，按权限和数据分级读取 |
| 协作内容 | 帖子、评论、公告、讨论、review | 可索引和摘要，但不能替代正式事实 |
| 模型上下文 | prompt、检索片段、tool 输入输出 | 按环境和数据分级隔离，默认不公开 |
| Observation | 日志、指标、trace、失败原因、人工修正 | 可进入评测和复盘，敏感字段需脱敏 |
| LearningArtifact | prompt 候选、workflow 候选、策略候选、知识摘要 | 只能作为候选进入评测、审批、灰度和回滚 |
| Eval sample | 固定样本、失败样本、对抗样本 | 必须版本化，不能包含未脱敏敏感原文 |
| DesensitizedTrainingResource | 脱敏后的训练、评测或模型能力改进资源 | 必须有脱敏证明、用途、owner、审批和保留期 |
| Community Commons | 用户明确发布的模板、工具契约、脱敏摘要和案例 | 默认只接收显式授权资产 |

## 脱敏后训练资源

敏感数据可以在脱敏后保留为训练资源，但必须满足以下条件：

1. 原始敏感数据不得直接作为训练资源保留。
2. 脱敏过程必须移除或不可逆转换直接标识符和高风险间接标识符。
3. 仅替换姓名、手机号或身份证号但仍可通过组合字段还原个人身份的内容，不得视为合格训练资源。
4. 训练资源必须绑定来源引用、脱敏方法、脱敏执行者、审批引用、用途、适用范围、保留期和撤回路径。
5. 训练资源只能用于声明的用途，例如评测、评分器校准、提示词改进、模型路由能力评估、模板质量改进或经审批的模型训练。
6. 使用外部模型供应商进行训练、fine-tuning 或长期存储时，必须确认供应商的数据保留、训练使用、删除、区域、加密和审计能力。
7. 训练资源不得进入 Community Commons 或跨实例共享，除非再次通过公开分享授权和脱敏检查。

可逆脱敏、假名化或只做字段遮盖的数据仍应保留较高数据分级。只有在重识别风险经评估并被接受后，才允许降低数据分级或扩大使用范围。

## 训练资源元数据

每个 `DesensitizedTrainingResource` 至少包含：

- `trainingResourceId`
- `sourceRefs`
- `projectInstanceId`
- `sourceDataClassification`
- `currentDataClassification`
- `desensitizationMethod`
- `desensitizationVersion`
- `residualReidentificationRisk`
- `allowedUses`
- `disallowedUses`
- `owner`
- `approvalRef`
- `auditEventId`
- `retentionUntil`
- `revocationPolicy`
- `modelRouteRestrictions`
- `sharingScope`

缺少来源、用途、审批、脱敏方法或保留期的训练资源不能进入评测、训练或共享流程。

## 允许用途

脱敏训练资源可用于：

- 离线评测样本。
- 评分器校准。
- 失败模式分类。
- prompt / workflow 候选评估。
- `ModelCapabilityProfile` 评测。
- `TaskFitAssessment` 公平性和质量评测。
- 模板质量改进。
- 经审批的本地模型训练或供应商受控训练。

禁止用途：

- 还原个人身份。
- 生成个人绩效、惩罚或排除机会的自动结论。
- 绕过原始数据的权限和审批。
- 作为公开案例或 Commons 资产默认发布。
- 发送给未绑定合格 `ModelRoute` 和供应商数据治理证明的外部模型。

## 生命周期

### 1. 采集

- 明确数据来源、用途和 owner。
- 绑定 `ProjectInstance`、环境、数据分级和权限范围。
- 避免采集任务无关字段。

### 2. 使用

- 业务主数据由控制面维护。
- 模型上下文只传最小必要片段。
- `restricted` 和 `sensitive` 数据优先摘要化、本地处理或人工处理。

### 3. 脱敏

- 使用可复核的脱敏流程。
- 记录输入引用、输出引用、方法版本、执行者和审批。
- 对训练用途进行重识别风险评估。

### 4. 保留

- 每类数据必须有保留期。
- 训练资源保留期不能长于其用途需要。
- 审计日志可以保留更久，但不得复制敏感明文。

### 5. 撤回与修正

- 用户可撤回公开分享许可。
- 成员可请求修正与自己相关的画像、贡献记录或训练资源元数据。
- 撤回不应破坏必要审计，但应停止后续训练、公开分享或跨实例传播。

### 6. 删除与归档

- 删除应覆盖主数据、索引、缓存、导出物、模型上下文和后续备份生命周期。
- 无法立即从不可变备份删除时，必须记录到期清除时间和恢复后再删除规则。
- 已公开或跨实例传播的资产必须发布撤回或更正记录。

## 与学习飞轮的关系

`Observation`、失败样本、人工修正和审批结果可以进入学习飞轮，但进入评测、训练或共享前必须通过数据生命周期检查。

学习飞轮不得把以下内容直接转为训练资源：

- 未脱敏敏感字段。
- 原始模型上下文。
- 内部任务内容。
- 成员隐私画像。
- 未经授权的业务材料。
- 可识别个人身份的失败案例。

## 与跨实例共享的关系

跨实例默认只能共享 `SharedTemplate` 和 `SharedEvalSummary`。即使训练资源已经脱敏，也不能默认跨实例共享。

若确需共享训练资源的派生摘要，必须满足：

- 使用 `SharedEvalSummary` 聚合表达。
- 不包含原始上下文。
- 不包含可重识别个人、组织或内部任务的字段。
- 绑定 `FederationLink`、数据共享等级、审批引用和审计事件。

## 安全事件

以下情况必须按安全事件处理：

- 敏感原文被保存为训练资源。
- 脱敏训练资源被发现可重识别个人或组织敏感事实。
- 未经审批的训练资源进入外部供应商。
- 训练资源被公开分享或跨实例传播但缺少授权。
- 撤回后仍继续用于训练、评测或公开传播。

处理方式包括冻结相关资源、停止训练或评测任务、撤销公开资产、轮换相关凭据、复盘脱敏流程并补充评测样本。

## 验收要求

新增任何训练、评测、学习或共享能力时，必须回答：

- 是否声明数据来源、owner、用途和保留期。
- 是否继承原始数据分级和使用限制。
- 是否完成脱敏和重识别风险评估。
- 是否有审批、审计和撤回路径。
- 是否限制外部供应商训练或长期存储。
- 是否禁止未脱敏敏感数据进入评测、训练和公开资产。
