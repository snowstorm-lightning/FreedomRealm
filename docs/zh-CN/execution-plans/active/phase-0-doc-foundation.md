# Phase 0: 文档底座建设计划

## 目标

把 AI-HRMS 的仓库从“旧玩具项目目录”转成“新 agent-first 系统的文档真相来源”。

## 范围

- 根入口文档
- 中文知识库
- ADR
- 执行计划索引
- 评测基线

## 不在范围内

- 删除旧项目目录
- 编写业务代码
- 初始化 Git

## 交付物

- `README.md`
- `AGENTS.md`
- `ARCHITECTURE.md`
- `docs/zh-CN/` 下的专题文档

## 细化任务

- 补齐环境隔离、防污染、晋级和回滚方案。
- 补齐接口契约中的全局封套、错误码、事件封套和 ToolContract 边界。
- 补齐业务状态机、风险分级、ApprovalGate 和 AgentRun 生命周期。
- 补齐质量门禁中的环境隔离、Agent 安全回归和 Definition of Done。
- 补齐评测基线中的样本元数据、评分规则和发布阈值。

## 风险

- 文档术语漂移
- 后续实现阶段偏离当前边界
- 自治能力被误解为“自动改生产代码”

## 验收

- 文档能独立描述新系统，不依赖旧目录
- 关键角色、边界、流程、事件、审批和回滚设计完整
- 删除旧项目后仓库仍保有完整设计上下文
- 后续实现团队可以从文档直接推导最小代码仓结构、环境隔离要求、接口边界和测试门禁
