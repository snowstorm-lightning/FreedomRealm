# AI-HRMS Web Workbench

This app is the Web-first onboarding surface for Demo Mode.

Current constraints:

- It is a static demo build.
- It reads data generated by the shared `packages/demo` execution layer.
- It must not duplicate CLI business logic.
- It must not require login, a live model key, an external connector, or real HR data.

Local command from the repository root:

```text
pnpm web:demo
```

The generated page is written to `dist/web/index.html`.

The current build renders five built-in templates:

- `repo_understanding_and_work_plan`
- `knowledge_navigation_and_challenge`
- `issue_pr_triage_and_review`
- `personal_work_proof`
- `docs_review_and_improvement`

Each template produces a canonical JSON `ExecutionReportCard` and a Markdown render under `dist/web/data/`.

The build also renders three built-in `Ask maintained docs` examples. Each example is generated by the shared knowledge/demo layer and writes:

- `AnswerCard` JSON
- `DocChallengeDraft` JSON
- `ExecutionReportCard` JSON / Markdown
